# Cyborg Landing Page 🚀

This is a responsive futuristic Cyborg-themed landing page built using HTML and CSS.

## 🔥 Features
- Modern cyberpunk UI/UX design
- Fully responsive layout (mobile + desktop)
- Neon glow effects and glassmorphism UI
- Smooth scrolling navigation
- Interactive sections (Hero, About, Features, Stats, Contact)

## 🛠️ Technologies Used
- HTML5
- CSS3
- Google Fonts (Orbitron)

## 📁 Project Structure
- index.html (Main file containing all HTML, CSS, and UI design)

## 🚀 How to Run
1. Download or clone the repository
2. Open `index.html` in any web browser

## 📌 Purpose
This project was created as a Techfest-style submission to demonstrate creative UI/UX and responsive web design skills.
